– Developed power-law and Langmuir–Hinshelwood kinetic models for furfural conversion to 2-methylfuran.
– Formulated single-site and dual-site mechanistic models incorporating adsorption and surface reaction phenomena.
– Estimated kinetic and thermodynamic parameters using nonlinear regression of experimental reactor data.
